# Primos Code · Landing page

Página estática (um único `index.html`, sem dependências externas).

## Antes de publicar
No `index.html`, troque `5547999999999` (linha do `window.PRIMOS_WA`) pelo número real do WhatsApp (DDI + DDD + número, só dígitos).

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub (ex.: `primos-code-landing`).
2. Envie os arquivos `index.html`, `.nojekyll` e `README.md` para a branch `main`.
3. Em **Settings → Pages**, em *Build and deployment*, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)` e salve.
4. Aguarde 1 a 2 minutos. A URL será `https://SEU-USUARIO.github.io/primos-code-landing/`.

## Medir
Abra https://pagespeed.web.dev/, cole a URL publicada e rode. Tire print do resultado **Celular** e do **Computador** com a data visível.
